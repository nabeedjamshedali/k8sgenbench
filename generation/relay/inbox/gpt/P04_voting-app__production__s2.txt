# Production deployment notes:
#
# 1. Replace the placeholder PostgreSQL password using a secrets manager.
# 2. Replace :latest image tags with immutable, tested image digests.
# 3. Configure a production StorageClass with encryption and backups.
# 4. Provision voting-app-tls through cert-manager or another TLS provider.

# 7. Verify that the ingress controller matches the NetworkPolicy selector.
# 8. The application frontends are originally designed to serve at "/".
#    For /vote and /result routing, configure path rewriting or use
#    separate hostnames to avoid broken assets and relative URLs.
# 9. The prebuilt example images may use hard-coded database credentials;
#    verify their configuration support before changing the original
#    PostgreSQL credentials.
# 10. Kubernetes NetworkPolicies require a compatible CNI plugin.
# 11. For high availability, use managed PostgreSQL and Redis services
#     with automated failover, monitoring, and recovery procedures.
# 12. The optional seed service is intentionally omitted because its
#     image must be built from the local seed-data directory.
